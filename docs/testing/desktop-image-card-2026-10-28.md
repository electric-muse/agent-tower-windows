# 桌面回复中的本机图片路径投递回归

- 现象：已完成的 Codex 桌面回复含 Markdown 本机图片路径时，飞书卡片接口返回 HTTP 400 / 230099，桌面绑定一直处于等待回复状态。
- 诊断：飞书错误详情为 `card contains invalid image keys`，指向本机文件路径。长连接在线不代表卡片投递成功。
- 修复：控制与播报发送入口将 Markdown 图片引用转成文字说明，保留图片名称和路径；普通链接不变。已入库的失败播报在显式重试时也经过同一转换。
- 离线验证：`python -m unittest test_desktop_control test_management`，52 项通过；测试覆盖两个发送入口和普通链接保留。
- 本机联调：重启塔台后，原桌面会话的待发送回复获飞书接口接受，等待标记清除；健康快照显示长连接及两个循环正常。旧失败播报未批量重投。
- 独立限制：机器人上传实际图片仍缺少飞书 `im:resource:upload` 权限；该修复只确保文字回复可投递。Codex 桌面页仍出现“ChatGPT 遇到了问题”，后端会话可读；客户端更新状态为 `restart_required`，重启客户端后的显示效果尚未验证。
