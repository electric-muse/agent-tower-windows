# 测试与验证边界

在已安装依赖的 Python 环境中运行：

```sh
PYTHONDONTWRITEBYTECODE=1 python scripts/run_tests.py
```

离线测试在临时目录复制源码和配置模板，使用虚构数据，阻止测试 Python 进程连接网络，不复制本机凭据或运行状态。请通过 `TMPDIR` 指定空间充足的临时目录。

覆盖任务控制、会话观察、投递恢复、卡片交互、原生问题回填与看门狗等行为。离线通过不代表真实飞书鉴权、消息回调、模型 CLI 或客户端显示已验证；这些需在使用者自己的授权测试环境中单独检查。

公开仓库不附带真实会话转录、运行日志、账号配置或历史客户端截图。
